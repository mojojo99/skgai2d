Generative AI has read a huge amount of text and learned to predict the most likely next word, again and again, to build an answer.

Finish this order at the kopitiam:

"Kopi O ais, kurang ___"

You just predicted the next word. AI does the same, billions of times, with much more context.

1 · Trained

Learns language patterns from books, websites and code.

2 · Prompted

Your instruction and files give it the context to work with.

3 · Generates

Writes a fluent answer word by word. Fluent ≠ always correct.

  • Let the room shout the answer ("manis"). Point out AI picks the most likely word, not the true one.
  • Key message: AI sounds confident because it is built to produce fluent text, not because it has checked facts. Many tools can now also search the web, which helps with current information, but you still verify.

AI → Machine learning → Generative AI

Nested ideas: ML learns patterns from data; generative AI uses them to create text, images and code.

Large language model (LLM)

The engine behind ChatGPT, Claude, Gemini and Copilot: predicts the next word.

Training data & knowledge cutoff

What it learnt from, and the date its knowledge stops (unless it searches the web).

Token · context window

Tokens are word-pieces. The context window is how much text it can consider at once.

Hallucination

A confident answer that is false or made up. Why we C.H.E.C.K.

Human-in-the-loop

A person reviews and decides before anything is used. That is you.

Multimodal

Works with more than text: images, screenshots, voice, files.

Agent

AI that plans and carries out several steps toward a goal, using tools.

1. AI looks up answers in a database of correct facts.
Myth. It generates answers from learned patterns. Some tools add web search, but the answer is still generated.
2. AI can be confidently wrong, and can even invent laws and sources.
Fact. This is called a "hallucination". Always verify facts, figures and references.
3. If I upload a spreadsheet, the AI's totals are always right.
Myth. Tools that run calculations are usually accurate, but they can read the wrong column or skip rows. Check key totals in Excel.
4. The same prompt can give a different answer each time.
Fact. Outputs vary. That is useful for ideas, and a reason to save prompts that work well.
5. Free AI tools cannot create real Word or Excel files.
Myth. Some free plans can now create .docx, .xlsx and .pptx files (we use this today), with daily limits.
6. AI will replace my job.
Myth for most roles. AI replaces tasks. People who use AI well tend to take over the tasks of those who don't.

⚖️ Bias

AI learns from human data, so it can repeat unfair patterns. Never let it rank people for hiring, promotion or discipline without a human review.

🧩 Five kinds of AI harm

Allocative (unfair access to jobs or loans) · Quality-of-service (works worse for some groups or accents) · Representational (stereotypes) · Social system (misinformation) · Interpersonal (misuse against a person).

🎭 Deepfakes

Fake voice, photo or video of a real person. Verify unusual requests from a "boss" by phone, especially payment requests.

📣 Disclose AI use

Tell readers when AI helped draft or analyse. You stay accountable for every number and word.
